# JD Longmire Atlas (Public)

The public face of the JD Longmire Atlas, the map and record of James (JD) Longmire's work.

The Atlas of record is a private repository. It holds the full corpus map, the decision and work record, and the successor's brief. This public repository is the curated front door: the public programs, the publications, and the links, published as a GitHub Pages site for quick reference.

Nothing private is published here. Content arrives in this repository only by deliberate curation from the private Atlas.
